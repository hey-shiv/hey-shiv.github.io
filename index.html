01 — Flagship work

Flagship work

Live · negative result Data analysis · Backtesting

Coil

Does a famous chart pattern beat buying on a random day?

A screener that scans 2,300 NSE stocks for a Volatility Contraction Pattern, paired with a ten-year backtest built to disprove it. Every past signal is replayed from only what was known at the time, then compared with random entries in the same stocks at the same risk. The random entries won.

  • 2,300Stocks scanned
  • 10 yrsPoint-in-time backtest
  • 11.0% vs 22.3%CAGR, pattern vs random

Building Machine learning · Retrieval

Cover Song Retrieval

Can a machine recognise a song it has never heard?

Given one recording, find every other recording of the same composition across changes of key, tempo and voice. The classical baseline comes first: chroma features, key alignment and subsequence DTW, with MAP, MRR and Recall@K written and unit tested before any learned model exists. No scores yet; the benchmark run is next.

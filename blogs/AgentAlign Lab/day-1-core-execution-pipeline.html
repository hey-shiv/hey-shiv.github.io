Day 1 — What I Actually Built

Today I learned how reliable AI coding agents work internally.

Instead of building a chatbot, I built the core execution pipeline behind coding-agent systems.

The system flow is:

  1. Task JSON
  2. Schema Validation
  3. Temporary Workspace Creation
  4. File Materialization
  5. Pytest Execution
  6. Structured Verifier Result

What This Means in Simple Words

I created a system where:

  • a coding task is stored as structured JSON
  • Python loads and validates the task using Pydantic
  • the system creates an isolated temporary folder (sandbox)
  • task files are automatically generated there
  • pytest runs automatically inside that workspace
  • the system captures pass/fail results and logs

The verifier successfully detected an intentionally broken bug:

pytest -q 
FAILED test_task.py::test_expected_output

    def test_expected_output():
>       assert 3.0 == 2
E       assert 3.0 == 2

1 failed in 0.04s

which proved the full pipeline works correctly.

The important part was not that the test failed. The important part was that the system created, ran, captured, and returned the failure in a structured way.

System Architecture Built Today

The pipeline is small, but every box has a job. The task starts as data, becomes a typed object, gets materialized into an isolated workspace, and then gets judged by a verifier.

Biggest Concepts Learned

Pydantic validation
Raw Dict -> Validated Schema
Sandbox isolation
Filesystem vs Sandbox
Deterministic verification
LLM Opinion -> pytest pass/fail

1. Pydantic

Used to create structured validated schemas.

Instead of random dictionaries, the system uses proper typed objects.

Example:

class Task(BaseModel):

This keeps the system reliable and organized.

2. Nested Models

A Task contains:

  • files
  • verifier configuration

This creates clean hierarchical system design.

3. Sandboxed Execution

Tasks run inside temporary isolated workspaces:

/tmp/random_workspace/

This prevents agents from touching the real filesystem.

4. subprocess

Python can execute terminal commands programmatically.

Example:

subprocess.run(["pytest", "-q"])

This is how coding agents run tools automatically.

5. Deterministic Verification

The system does not rely on subjective judging.

Instead:

pytest pass = success
pytest fail = failure

This makes evaluation measurable and reliable.

Biggest Realization

Reliable AI systems are built more on:

  • execution
  • verification
  • structure
  • evaluation

than on prompting itself.
